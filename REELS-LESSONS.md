# Монтаж відео з Claude Code

Лара Герман · Lara German Design School

Два практичні уроки українською для студентів-дизайнерів.

| Урок | Як працюємо |
| --- | --- |
| 6. Монтаж відео з Claude Code. Варіант 1 | Готові запити по черзі: перевірка тексту, монтаж, оформлення й збереження стилю |
| 7. Монтаж відео з Claude Code. Варіант 2 | Скілл lara-german-reels, власні фотографії за бажанням і повторення стилю |

[Скачати скілли та матеріали уроків](./LaraGerman-Reels.zip)

Архів містить обидва уроки, готові запити, скілл, загальну методичку PDF і Word та підготовлені папки. Розпакуйте його, скопіюйте повну адресу папки LaraGerman-Reels і надішліть її у чат Claude Code разом із першим запитом свого уроку.

Помістіть своє відео в папку «Відео», а вибрані фотографії й матеріали бренду — в папку «Матеріали». Приклад бажаного оформлення можна додати файлом або надіслати посилання на конкретне відео в Instagram.

Авторка навчальної методики, запитів та оформлення — Лара Герман. Комплект доповнює інші матеріали цього репозиторію. Власні відео студентів до нього не входять.

Перевірено структуру комплекту, цілісність ZIP, актуальні тексти обох уроків і копіювання запитів у Softbook. Дев’ять сторінок загальної методички раніше експортовано Microsoft Word та перевірено візуально. Монтаж студентського відео перевіряють під час практичної роботи з фактичним відео та інструментами.
