## Початок роботи

1. Розпакуйте LaraGerman-Reels.zip повністю.
2. Відкрийте папку LaraGerman-Reels у локальній сесії Claude Code.
3. Для варіанта 1 прочитайте docs/lesson-6.md і використовуйте готові TXT-запити з цієї папки.
4. Для варіанта 2 перевірте .claude/skills/lara-german-reels/SKILL.md та відкрийте docs/lesson-7.md.
5. У комплекті вже є зрозумілі папки: «Відео» — для вашого запису, «Матеріали» — для фото, прикладів оформлення та брендбуку. Робочі файли й готові ролики Claude збереже у відповідних папках.

Комплект містить власні навчальні інструкції школи. Це додатковий практикум; він не замінює інші матеріали цього репозиторію. Моделі розпізнавання та FFmpeg не включені до ZIP — Claude Code має перевірити й підготувати їх у вашому середовищі. Самостійно програмувати не потрібно.

Авторка навчальної методики, запитів та оформлення — Лара Герман. Використані сторонні програми належать їхнім розробникам. Власні відео й робочі файли студентів до репозиторію не додаємо.

## Перевірено у цій редакції

Структуру скіллу, цілісність ZIP та всі дев’ять сторінок експорту Microsoft Word. Наскрізний відеорендер на студентському матеріалі не виконувався: його перевіряють під час практичної роботи з фактичним відео та інструментами.
