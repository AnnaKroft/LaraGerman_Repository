# Шрифти для монтажу

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Ліцензія Manrope: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- JetBrains Mono: https://www.jetbrains.com/lp/mono/
- Ліцензія JetBrains Mono: https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt

Обидві гарнітури поширюються за SIL Open Font License 1.1. Для поширення
самих файлів збережіть повні тексти ліцензії й copyright notice.
У цих навчальних архівах надаються посилання, файли шрифтів не включені.

Рекомендовані пари:

- Manrope ExtraBold + Manrope Regular.
- Manrope ExtraBold + JetBrains Mono Medium.
- JetBrains Mono Bold + Manrope Regular.

Перед рендером перевірте Ґґ Єє Іі Її у вибраному файлі.
Конкретні BebasNeueCyrillic.ttf і Gogol-Regular.otf не включайте в спільний
пакет без підтверджених джерела й умов поширення.
